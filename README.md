# 工业协议转换网关（虚拟协议首轮）

本项目只连接本地、进程内或 loopback 上的模拟设备，不包含任何真实控制设备驱动。

## 两套明确限定的虚拟协议

### REG（虚拟寄存器协议）
固定 8 字节帧，字段均为大端：

```
0xA5 | func | regHi regLo | valueHi valueLo | crcLo crcHi
```

- `func=0x03` 读：`value` 为点数（1..16）；响应回读单个寄存器值。
- `func=0x06` 写：`value` 为写入值；响应原样回显。
- 异常：功能码最高位置 1，`value` 为异常码。
- CRC 为 CRC-16/MODBUS，校验前 6 字节。
- 接收端允许 TCP 分片，必须凑满 8 字节并校验 CRC 后才处理。

### TAG（虚拟标签协议）
固定 14 字节请求 / 12 字节响应，数值字段均为小端：

```
请求: 'T' 'Q' | op | reserved | seq(u32 LE) | tag(u16 LE) | value(f32 LE)
响应: 'T' 'R' | status(u16 LE) | seq(u32 LE) | value(f32 LE)
```

## 转换规则

- 字段映射同时描述数据类型、字节顺序、缩放/偏移、工程量单位和范围。
- 当前支持 `uint16`、`int16`、`float32`，以及摄氏度/华氏度、kPa/psi 换算。
- NaN、无穷大、越界、负数写入无符号类型、小数写入整数寄存器等不可表示值一律返回错误。
- 整数编码按真实范围检查，绝不靠溢出截断“成功”。
- 每笔操作由 `OperationID` 关联，记录两侧分帧、十六进制报文、阶段、结果或错误。
- 写请求发出后若超时或断连，结果状态保留为 `unknown`；网关不会自动重试，避免把一次逻辑写操作变成两次现场动作。

