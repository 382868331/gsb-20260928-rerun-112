# 工业协议转换网关

这是一个只使用本地连接和虚拟设备的 Go 参考实现。代码不包含真实控制设备地址、驱动或自动重连写入逻辑。

## 首轮协议

- `alpha-fixed-binary`：9 字节大端二进制定长帧，包含地址、功能码、寄存器、有符号 16 位值和 CRC。
- `beta-length-tlv`：小端长度前缀 TLV 帧，包含操作码、标签长度、标签、32 位整数和校验尾。
- 字段映射由 `DefaultMappings()` 显式声明，当前包含温度、压力和温度设定值。

## 多字段逻辑操作

批量 Alpha 帧与单字段帧共享 `0xA5 + 2 字节地址 + 功能码` 头部，功能码为 `0x23`（批量读）和 `0x26`（批量写），随后是 1 字节字段数和每项的 `2 字节寄存器`（写操作再带 `2 字节有符号值`）。响应为 `头部 + 总体状态 + 快照字节 + 每项状态/值`。

- 多字段读取通过逐个独立往返完成，每个字段记录自己的采样时刻 `observed_at`；响应快照字节固定为“非同一设备时刻”（`0x00`），无法保证时绝不伪装成原子快照。只有适配器能证明同一采样瞬间时才允许置为 `0x01`。
- 多字段写入逐项转换、逐项发送，字段状态分别为 `completed`、`failed`、`unknown`；总体状态汇总为 `completed`、`partial` 或 `unknown`。任一项失败都不会盲目重发整批，每项 `Attempts` 始终为 1。
- 单位换算不能由目标整数精确表示时（如整数 kPa 落到非整数 psi 原始值），该项在本地拒绝且不发送任何报文；其他字段不受影响。
- 每个字段在轨迹中保留独立的转换前后值、标准单位值、错误和字段级报文十六进制证据（`TraceField.Frames`）。

## 不确定写入的核实

写请求已发出但响应丢失、超时或连接在响应前断开时，该字段保持 `unknown`。调用者不应假定修改未发生，也不会触发第二次写入；后续路径是：

1. 沿 `verify_path` 事件提示，对目标 Beta 标签做一次新的读回；
2. 或调用 `Channel.VerifyUncertainWrites(ctx, trace)`，它对每个 `unknown` 字段执行独立读回并比对发送值，结果为 `applied`、`not_applied` 或 `uncertain`；
3. 核实读本身失败时结果是 `uncertain` 而不是 `not_applied`——超时的修改可能已经生效，不能仅凭没收到确认就认定未发生。

## 转换与拒绝

- 每个端点声明数据类型、字节顺序、工程单位、缩放、偏移和原始范围。
- 转换路径是“原始值 → 工程单位 → 标准单位 → 目标工程单位 → 目标原始值”。
- 超范围、非有限数和不能由目标整数精确表示的值直接返回错误，不做静默截断。
- 压力映射演示 kPa 与 psi 的单位换算；温度支持摄氏度、华氏度和开尔文。

## 请求跟踪

`TraceStore` 可按随机事务 ID 查询一次操作的完整信息：
- 入站 Alpha 帧和出站 Beta 帧的方向、协议和十六进制内容。
- 入站 Beta 响应和出站 Alpha 响应。
- 字段映射、换算前后的值、标准单位值、事件时间线、耗时、状态和错误。
- `Attempts` 始终为 1；写入超时、响应前断连或收到未知状态时保留 `unknown`，网关不会重试成第二次写入。

## 本地验证

模拟设备使用 `net.Pipe` 或本地 listener，不连接真实硬件：

```sh
go test ./... -count=1 -race
```

测试覆盖温度缩放边界、压力不可精确表示拒绝、Beta 单字节分段消息、端序、响应前断连、写入超时、事务轨迹查询，以及多字段读取的非同一时刻标记、第二项设备拒绝时的字段级状态与报文证据、本地换算不精确不发送、丢失确认后的读回核实（含核实仍失败时保持 `uncertain`）。

## 扩展适配器

新协议实现 `Upstream` 接口，并通过 `NewChannel(..., mappings...)` 显式注册字段映射即可。通道继续通过同一个 `TraceStore` 记录完整来回；新增适配器不得在写入结果不确定时自行重试。
